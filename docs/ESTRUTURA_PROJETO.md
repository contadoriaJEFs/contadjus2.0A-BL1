# Estrutura do projeto ContadJus

A raiz do projeto mantém apenas os arquivos essenciais da aplicação. Os demais arquivos são organizados por finalidade:

- `index.html` — aplicação principal.
- `CNAME` — configuração do domínio do GitHub Pages.
- `README.md` — apresentação e instruções gerais.
- `assets/` — imagens e recursos visuais.
- `css/` — folhas de estilo.
- `data/` — bases de índices, parâmetros e dados estruturados.
- `docs/` — documentação técnica, glossário, contexto e tutoriais.
- `js/` — motores, módulos e lógica da aplicação.
- `changelog/` — changelogs e relatórios históricos de desenvolvimento.
- `testes/` — scripts e artefatos de testes.
- `planejamento/` — roadmap e melhorias futuras.
