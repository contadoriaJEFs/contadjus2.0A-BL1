# B108 — Estrutura DOM das linhas ciano

- Base: B107.
- Correção focada exclusivamente na estrutura das linhas ciano.
- Linhas separadoras com múltiplas células vazias passam a usar uma única célula com `colspan` quando identificadas.
- Linhas de totais recebem `page-break-inside: avoid`.
- Nenhum `font-size` foi alterado.
- Nenhum motor, fórmula ou regra de negócio foi alterado.
