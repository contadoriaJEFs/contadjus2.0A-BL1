# Glossário ContadJus — linguagem simples

Este glossário explica, em termos de leigo, os principais elementos usados no sistema.

| Termo | Explicação simples |
|---|---|
| **Guia** | Uma das etapas do sistema, organizada por finalidade. |
| **Motor de cálculo** | Parte do código que efetivamente faz as contas. |
| **RMI** | Renda Mensal Inicial do benefício. |
| **RMA** | Renda Mensal Atualizada após os reajustes aplicáveis. |
| **DIB** | Data de Início do Benefício. |
| **DIP** | Data de Início do Pagamento. |
| **DCB** | Data de Cessação do Benefício, quando existente. |
| **Competência** | Mês/ano ao qual determinado valor se refere. |
| **PRO RATA** | Reajuste proporcional aplicado quando o primeiro reajuste não é integral. |
| **INTEGRAL** | Reajuste aplicado integralmente à competência correspondente. |
| **Fallback** | Regra alternativa usada quando não há um índice específico disponível para determinada situação. |
| **Teto** | Limite máximo previdenciário aplicável ao benefício. |
| **Salário mínimo** | Piso utilizado nas situações em que o benefício é vinculado ao salário mínimo. |
| **Valor teórico** | Valor obtido pela evolução matemática antes de determinados limites. |
| **Valor evoluído** | Valor resultante da aplicação da evolução do benefício. |
| **Valor final** | Valor efetivamente considerado depois das regras de piso, teto e demais tratamentos aplicáveis. |
| **Diferença devida** | Valor que deveria ter sido pago menos o que foi efetivamente recebido, conforme as regras do sistema. |
| **Correção monetária** | Atualização do valor para compensar a variação monetária no período. |
| **Juros de mora** | Acréscimo aplicado pelo atraso, segundo o critério definido para o cálculo. |
| **SELIC** | Índice/taxa utilizado pelo sistema quando o critério do cálculo determinar sua aplicação. |
| **Encadeamento** | Sequência de regras e períodos que define qual índice deve ser usado em cada competência. |
| **Parâmetro** | Informação ou regra fornecida ao motor para realizar o cálculo. |
| **Container** | Caixa visual que agrupa informações na tela. |
| **Altura responsiva** | Altura que se adapta ao conteúdo e ao tamanho disponível da tela. |
| **Modal** | Janela que aparece sobre a tela para uma ação específica. |
| **Accordion / bloco recolhível** | Bloco que pode ser aberto ou fechado para economizar espaço. |
| **Estado visual** | Aparência usada para indicar a situação de um campo ou informação. |
| **JSON** | Formato de arquivo usado pelo sistema para salvar e recuperar dados estruturados. |
| **Relatório profissional** | Documento gerado a partir dos resultados consolidados, sem reproduzir a aparência da tela operacional. |
