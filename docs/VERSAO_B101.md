# ContadJus B101

## Ajuste cirúrgico — paginação do PDF

- Preservado integralmente o tamanho das fontes do PDF.
- Corrigida a área útil inferior da página para impedir que o rodapé fixo sobreponha/corte linhas.
- Mantida a continuidade das tabelas entre páginas.
- Mantido o cabeçalho das tabelas como `table-header-group` para repetição na continuação.
- Mantidas as linhas como unidades indivisíveis (`break-inside: avoid`).
- Nenhum motor ou função de cálculo alterado.
- Nenhuma regra de tamanho de fonte foi alterada nesta versão.
