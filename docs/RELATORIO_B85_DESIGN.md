# B85 — Diretrizes visuais do relatório

## Base
B85 deriva diretamente da B84 (`CONTADJUS-B84-TIPOGRAFIA`).

## Escopo
Somente apresentação visual e composição do relatório profissional. Nenhum motor de cálculo, índice, regra, estrutura de dados ou JSON foi alterado.

## Decisões
- `Competência` → `Comp.` nas tabelas das memórias.
- `Vlr. Teórico` e `Vlr. Evoluído` preservados.
- `Vlr. Final` recebe maior largura.
- Valores finais permanecem em uma linha.
- `Tipo` e `Status` recebem compactação horizontal.
- Guia 4 recebe espaçamento vertical moderadamente maior.
- Rodapé institucional discreto, com linha teal, na impressão.
